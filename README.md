# Лабораторная работа №1

## Вариант 4

### 1. Постановка задачи

**Задание 1.** Вычислить значение выражения при типах данных `float` и `double`:

$$\frac{(a+b)^3 - a^3}{3ab^2 + b^3 + 3a~2b}$$

при a = 1000, b = 0.0001 с использованием промежуточных переменных. Сравнить и объяснить результаты.

**Задание 2.** Вычислить значения выражений и объяснить результаты:
1) `n++ * m`
2) `n++ < m`
3) `m-- > m`

---

### 2. Программа решения задания 1

```cpp
#include <iostream>
#include <iomanip>
#include <clocale>

using namespace std;

int main()
{
    setlocale(LC_ALL, "Russian");
    cout << fixed;

    // РЕШЕНИЕ 1: float
    cout << "Решение 1: float" << endl;

    float a_f = 1000.0f, b_f = 0.0001f;
    float ab_f = a_f + b_f;

    float ab3_f  = ab_f * ab_f * ab_f;              // (a + b)^3
    float a3_f   = a_f * a_f * a_f;                 // a^3
    float numer_f = ab3_f - a3_f;                   // числитель

    float ab2_f  = 3.0f * a_f * b_f * b_f;          // 3 * a * b^2
    float b3_f   = b_f * b_f * b_f;                 // b^3
    float a2b_f  = 3.0f * a_f * a_f * b_f;          // 3 * a^2 * b
    float denom_f = ab2_f + b3_f + a2b_f;           // знаменатель

    float result_f = numer_f / denom_f;

    cout << "(a+b)^3             = " << ab3_f    << "\n";
    cout << "a^3                 = " << a3_f     << "\n";
    cout << "числитель           = " << numer_f  << "\n";
    cout << "знаменатель         = " << denom_f  << "\n";
    cout << "результат (float)   = " << result_f << "\n\n";

    // РЕШЕНИЕ 2: double
    cout << "Решение 2: double" << endl;

    double a_d = 1000.0, b_d = 0.0001;
    double ab_d = a_d + b_d;

    double ab3_d  = ab_d * ab_d * ab_d;             // (a + b)^3
    double a3_d   = a_d * a_d * a_d;                // a^3
    double numer_d = ab3_d - a3_d;                  // числитель

    double ab2_d  = 3.0 * a_d * b_d * b_d;          // 3 * a * b^2
    double b3_d   = b_d * b_d * b_d;                // b^3
    double a2b_d  = 3.0 * a_d * a_d * b_d;          // 3 * a^2 * b
    double denom_d = ab2_d + b3_d + a2b_d;          // знаменатель

    double result_d = numer_d / denom_d;

    cout << "(a+b)^3             = " << ab3_d    << endl;
    cout << "a^3                 = " << a3_d     << endl;
    cout << "числитель           = " << numer_d  << endl;
    cout << "знаменатель         = " << denom_d  << endl;
    cout << "результат (double)  = " << result_d << endl;

    return 0;
}
```

### 5. Объяснение результатов задания 1

* **Ожидаемый результат:** Аналитически выражение равно **1**, так как после раскрытия куба суммы числитель становится тождественно равен знаменателю: 3a²b + 3ab² + b³.
* **Ошибка в `float`:** Тип `float` хранит всего **~7 значащих цифр**. При a=1000 значения кубов достигают миллиарда (10⁹), где минимальный шаг погрешности `float` равен 64. Реальная разность чисел (~300) искажается, что приводит к **потере точности при вычитании близких больших чисел** (получено 384 вместо ~300) и неверному итогу (≈ 1.280000).
* **Точность `double`:** Тип `double` хранит **~16 значащих цифр**. Этого хватает для точного вычисления разности на фоне больших чисел. Результат верный: 1.

### 6. Программа решения задания 2

```cpp
#include <iostream>
#include <clocale>

using namespace std;

int main()
{
    setlocale(LC_ALL, "Russian");
    int n, m, r;

    // 1) n++ * m
    n = 5; m = 3;
    r = n++ * m;
    cout << "1) n++ * m = " << r << ", n = " << n << ", m = " << m << "\n";

    // 2) n++ < m
    n = 5; m = 3;
    r = n++ < m;
    cout << "2) n++ < m = " << r << ", n = " << n << ", m = " << m << "\n";

    // 3) m-- > m
    n = 5; m = 3;
    r = m-- > m;
    cout << "3) m-- > m = " << r << ", n = " << n << ", m = " << m << "\n";

    return 0;
}
```

### 7. Результаты работы программы (Задание 2)


### 8. Объяснение результатов задания 2

* **`n++ * m`:** Постфиксный инкремент возвращает **старое** значение `n` (5), затем увеличивает `n` до 6. Вычисляется 5 × 3 = 15.
* **`n++ < m`:** Инкремент возвращает старое значение `n` (5). Сравнение 5 < 3 дает ложь (`0`), после чего `n` увеличивается до 6.
* **`m-- > m`:** Декремент возвращает старое значение `m` (3) и уменьшает переменную до 2. Правый операнд принимает уже обновленное значение (2). Сравнение 3 > 2 истинно (`1`). Начиная с C++17 порядок вычислений строго зафиксирован **слева направо**, что делает результат стабильным и исключает Undefined Behavior.
